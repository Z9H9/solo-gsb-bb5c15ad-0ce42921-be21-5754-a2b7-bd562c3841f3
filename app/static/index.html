🧶 编织行指令审校工具

逐行校验针数是否匹配，自动定位第一条无法执行的指令

行 指令 可用 · 消耗 · 产出 · 剩余

提示：在指令输入框中按 Enter 可快速插入下一行；修改任意行后自动重算后续所有行。

语法说明

指令含义消耗产出
kN平针 N 针NN
incN加针：1 针中织出 N 针1N
decN减针：N 针并为 1 针N1
[序列]*M将序列重复 M 次，可嵌套，如 [k2 [inc2 k1]*2]*3——
  • 指令之间可用空格、逗号或分号分隔；大小写不敏感（K2 与 k2 等价）。
  • 上一行的产出与未消耗针数之和，即下一行的可用针数。
  • 针数不足时会标出第一条无法执行的指令及短缺数量；行末有针未消耗时也会提示。

JSON 导入 / 导出格式

{
  "start": 12,
  "rows": ["k12", "[inc2 k1]*6", "[k2 dec2]*4 k2"]
}
